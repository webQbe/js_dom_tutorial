# JavaScript DOM Crash Course
This repo is an adaptation of [JavaScript DOM Crash Course](https://www.youtube.com/playlist?list=PLillGF-RfqbYE6Ik_EuXA2iZFcE082B3s) by Brad Traversy. 

I followed the tutorial to learn followings:
- Document Object Model
- Tree of nodes / elements created by the browser
    - `<html>` the root element
    - `<head>`, `<body>` elements of root element
    - `<title>` element of `<head>` element
    - 'My title' `text` of `<title>` element
- JavaScript can be used to Read/Write/Manipulate to the DOM
- Object Oriented Representation
